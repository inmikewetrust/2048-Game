2048

A sliding-tile number puzzle: merge matching numbers until you build the 2048 tile.

What is this game?

2048 is played on a 4×4 grid. Every tile holds a number, and every number is a power of two. You slide all the tiles in one direction at once, and when two tiles with the same number bump into each other they join into one tile with double the value.

The rules are simple, but the board fills up fast. Each move is a small decision about where the tiles will end up.

Purpose of this project

This version was built as our third web project. It brings together the three core web technologies: HTML for the page structure, CSS for the board and tile colours, and JavaScript for the game logic (moving, merging, scoring, and detecting a win or loss).

As a game, the purpose is to be a quick brain teaser: beat your own best score, climb the Local Top 5, and see if you can reach 2048.

How to play

  1. Press Start game. The board begins with a single tile, a 2.
  2. Press a direction key. Every tile slides as far as it can that way, and matching neighbours merge.
  3. If your move changed the board, a new 2 appears in a random empty cell. A move that changes nothing does not add a tile.
  4. Keep going. Each merge adds the value of the new tile to your score, so merging two 8s earns 16 points.

Winning and losing

You win when a 2048 tile appears. The status line reads WON and the game ends.

You lose when the board is full and no two neighbouring tiles match. The status line reads LOST.

When a game ends, you'll be asked for your name. Your score is saved to the Local Top 5 table below the board. These scores are stored in your own browser, so they stay on your device and aren't shared with other players.

Press Start game at any time to reset the board and your score.

Tips

  • Choose a corner and keep your biggest tile there.
  • Stick to two or three directions, and avoid the one that would pull the big tile out of its corner.
  • Build rows in descending order (for example 64, 32, 16, 8) so a single move can chain several merges.
  • Don't rush. Before each move, look at where the new 2 might land.
